# Ranked repositories by extraction value for VibeOS

This is not a fame ranking. It ranks how much reusable system design VibeOS can extract.

## Tier S — foundation
1. `obra/superpowers` — strongest full methodology; spec/plan/TDD/review discipline.
2. `mattpocock/skills` — strongest argument and examples for small composable skills instead of process bloat.
3. `EveryInc/compound-engineering-plugin` — strongest explicit “work should improve future work” loop.
4. `addyosmani/agent-skills` — strong lifecycle coverage and engineering quality gates.
5. `awrshift/claude-memory-kit` — strongest memory hygiene/promotion/handoff ideas found in the set.
6. `mattlgroff/pbc` — excellent fresh-agent execution packets and independent review architecture.
7. `garrytan/gstack` — strongest end-to-end public system with serious browser/design QA.
8. `hamelsmu/evals-skills` — strongest reminder that “agent says done” needs calibrated evidence/evals.

13. `steipete/poltergeist` — build freshness and feedback-loop tooling.

16. `pedrohcgs/claude-code-my-workflow` — strong requirement state, context survival and adversarial review patterns.
17. `humanlayer/12-factor-agents` — context/control-flow principles that prevent “LLM owns everything” architectures.
