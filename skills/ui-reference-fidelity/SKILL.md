# Reference fidelity

1. Identify the exact reference state, viewport/aspect ratio, content, and interaction state.
2. Compare macro structure first: composition, proportions, grid, hierarchy, major spacing, crop and alignment.
3. Then compare typography, color, borders/radii, shadows/materials, icon/image treatment, and motion/state details.
4. Distinguish intentional product adaptation from accidental drift; preserve required responsive behavior rather than forcing screenshot pixels everywhere.
5. Capture implementation evidence at the closest matching viewport/state.
6. Fix highest-perceptual-impact differences first, then re-capture.
7. Record unresolved deviations and why they remain.

Do not declare fidelity from memory of the reference. Keep the reference and implementation visible in the same review cycle.
